# Etykiety triage

Nazwy ról odpowiadają etykietom GitHub Issues:

- needs-triage: zgłoszenie wymaga oceny.
- needs-info: brakuje informacji od zgłaszającego.
- ready-for-agent: zgłoszenie jest gotowe do realizacji przez agenta.
- ready-for-human: zgłoszenie wymaga realizacji przez człowieka.
- wontfix: zgłoszenie nie będzie realizowane.

Gdy skill wskazuje rolę triage, stosuj dokładnie odpowiadającą
jej etykietę. Nie twórz zamienników istniejących etykiet.
